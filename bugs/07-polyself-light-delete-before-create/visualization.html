The false invariant

Being in a light-emitting form does not imply that a light source exists. Between set_uasmon() (polyself.c:815) and made_change: the hero is a glowing monster with no light source. The fix moves the transition to the form-installation boundary, which also covers the ~20 polymon() callers outside polyself.c that never reach made_change: at all.

Note: the id=0x… in the message is fmt_ptr() printing a pointer value; nothing invalid is dereferenced. This is a logic error, not memory unsafety.
